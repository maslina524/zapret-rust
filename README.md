# Zapret Rust
<img src="https://img.shields.io/badge/Windows-0078D6?logo=windows&logoColor=white" height=28 /> <img src="https://img.shields.io/badge/Made%20with-Rust-1f425f.svg?logo=rust&logoColor=white" height=28 />


**Zapret Rust** — это экспериментальная переработка известного инструмента zapret для обхода блокировок.
Проект задумывался как кросс-платформенное решение (в первую очередь для Linux), но пока доступен только для Windows с ограниченным функционалом.

**[Оригинальный репозиторий zapret](https://github.com/Flowseal/zapret-discord-youtube)**

> [!CAUTION]
> Перед использованием полностью отключите оригинальный zapret!
> Удалите его из автозагрузки (Remove Services) и остановите все связанные службы.
> В противном случае возможны конфликты и некорректная работа.

## 📦 Что внутри?

Все конфигурационные файлы, списки и исполняемые модули взяты напрямую из оригинального репозитория:

[/configs/](/configs/) — готовые стратегии обхода

[/lists/](/lists/) — списки ресурсов которые мы обходим

[/bin/](/bin/) — утилиты WinDivert и другие бинарные компоненты

Подробную информацию о настройке стратегий и параметрах запуска ищите в [официальной документации](https://github.com/Flowseal/zapret-discord-youtube/blob/main/README.md).

## 🛠️ Функционал

На данный момент реализован не весь функционал оригинального репозитория

**`Install Service`** - Устанавливает выбранную стратегию обхода в автозагрузку (как службу Windows).

**`Remove Services`** - Полностью удаляет службы стратегий и драйвер WinDivert из системы.

**`Check Status`** - Проверяет, активен ли обход, и отображает состояние установленных служб.

1. Скачайте последний релиз.
2. Запустите zapret-rust.exe от имени администратора.
3. В меню выберите нужное действие, следуя подсказкам.
